# analitika

> Analitika is a chart generator written in Python, which uses a JSON-based configuration

## Installation

1. (Optional but recommended) Create a virtual enviroment
```bash
uv venv
```
or 
```bash
python3 -m venv .venv
```
2. Install dependencies
```bash
uv sync
```
or
```bash
pip install -r requirements.txt
```

Done!
## How to use

```bash
python main.py <your config.json path> -o [output file path]
```

## Examples
> You can find examples for `pie_chart` and `bar` in [examples directory](/examples)
